Getting started

Purpose

This repository is an index and documentation hub for the AGN group.
Most code lives in separate repositories listed in repos.md.

Local setup

- Install the required Python and system packages for the specific repo
  you plan to use.
- Clone only the repos you need (see repos.md).

Contributing

- Open issues in the relevant repository.
- Keep documentation updates in this meta repo.
- Add new repos to repos.md with a short description and status.
