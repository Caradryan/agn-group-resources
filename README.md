AGN Group Resources

This is the meta index repository for the AGN group. It is a single
entry point to tutorials, shared tooling, and scientific packages
maintained in separate repositories.

Quick start

- New students: see docs/student-guide.md
- Researchers: see docs/workflows.md
- Repo catalog: see repos.md

How to use this index repo

- This repo is a curated entry point, not a code monorepo.
- Clone the specific repositories you need for your work.
- Keep guides, onboarding notes, and cross-repo docs here.
- Add new repositories to repos.md as they are created.

Migration note
